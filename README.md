# Irrigation Programs – Home Assistant add-on

Step-based irrigation programs for farms: mainlines with pump/main valve, blocks, programs made of
steps with overlap, three run modes (once / loop until a time / loop constantly), several programs
per mainline, live view, manual valve control and resume-after-restart.

Install: Settings → Add-ons → Add-on Store → ⋮ → Repositories → add this repository's URL,
then install **Irrigation Programs**. See `irrigation_programs/DOCS.md`.
