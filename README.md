# Irrigation Programs – Home Assistant add-on

Step-based irrigation programs for farms (mainlines, blocks, programs with steps and overlap,
once / loop-until / loop-constantly run modes) with a live view. Runs on top of the
[Irrigation Unlimited](https://github.com/rgc99/irrigation_unlimited) integration.

Install: Settings → Add-ons → Add-on Store → ⋮ → Repositories → add this repository's URL,
then install **Irrigation Programs**. See `irrigation_programs/DOCS.md`.
